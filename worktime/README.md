# 위례 근태·초과근무 관리 Tool

**선택적 근로시간제 30% 인원 맞추기**를 자동화합니다. 산출물은 두 개이고 역할이 다릅니다.

| 파일 | 어디에 두나 | 하는 일 |
|---|---|---|
| **`위례_근태관리.xlsx`** | **Teams · OneDrive 공유 폴더** | 모든 구성원이 **동시에** 편집. 30% 판정 · 조율 후보 · 월 총량 · OT 잔여 · 주별 64h 가 전부 자동 계산됩니다 |
| `index.html` | 각자 PC (더블클릭) | 탄력근무 **3개월 평균 52h** 판정, 목록에 없는 조합이 **왜 안 되는지** 설명, 상세 리포트 |

일상 업무는 엑셀만으로 끝납니다. HTML 도구는 달을 넘기는 계산과 규칙 설명이 필요할 때 씁니다.

> HTML 파일은 Office 문서가 아니라 Teams·OneDrive 공동 편집이 되지 않습니다(공동 편집은
> 저장소가 아니라 Office 앱 기능입니다). 그래서 함께 쓰는 기능은 전부 엑셀로 옮겼습니다.

## 엑셀 (Teams · OneDrive 공동 편집)

규칙을 통과하는 근무 조합은 106가지뿐입니다. 그 목록을 HTML 의 규칙 엔진에서 직접 뽑아
(`gen_combos.js`) 계산의 원천으로 씁니다. 다만 **106개를 한 드롭다운에 넣으면 고르기 어려워서**,
입력은 세 칸으로 나눴습니다.

| 칸 | 항목 수 | 내용 |
|---|---|---|
| **유형** | 11 | 근무 · 오전반 · 오후반 · 오전반반 · 오후반반 · 검진 · 연차 · 출장 · 교육 · 기타 · 휴직 |
| **출근** | 6 | 07:30 · 08:00 · 08:30 · 10:30 · 13:00 · 13:30 |
| **퇴근** | 18 | 11:30 ~ 20:30 (30분 단위) |

연차 · 출장 · 교육 · 기타 · 휴직은 **유형만** 고르고 시각은 비워 둡니다.
세 칸을 합쳐 조합표에서 찾으므로, **규칙에 없는 조합은 빨갛게** 표시됩니다
(예: `오전반 + 08:30~17:30`).

```
node worktime/gen_combos.js > worktime/data/combos.json   # 규칙 → 조합 106가지
python worktime/build_xlsx.py                             # 조합 → 엑셀
```

| 시트 | 내용 |
|---|---|
| **근태** | 행 = 구성원, 날짜마다 `유형 / 출근 / 퇴근` 세 칸. **빈칸이 8시간 근무**라 대부분은 비어 있습니다. 맨 아래 `8시간 인원 / 필요 인원 / 판정 / 직책자 8시간` 자동 계산, **미달일은 빨갛게**, **조율 후보는 노랗게** (출장·교육·연차는 후보에서 제외) |
| **OT** | 날짜별 OT 시간 (1시간 45분 = `1.75`) |
| **개인요약** | 소정근로일 · 기본 총량 · 휴가 · **조정 총량** · 실근로 · 총량 대비 · OT 합계/한도/잔여 · 8시간 일수 · **주별 근로시간(64h 판정)** |
| 명부 · 공휴일 | 인원 변동과 휴일 |
| 코드 · 시간 | 조합표와 계산용 (숨김) |

연·월(노란 칸)만 바꾸면 날짜·요일·휴일이 전부 따라옵니다. 수식은 시트 보호로 잠겨 있고
암호는 없습니다([검토] → [시트 보호 해제]).

> **동시 편집이 되려면** Excel Online(브라우저)으로 열거나 Excel 데스크톱에서 **자동 저장을
> 켜고** 열어야 합니다. 파일을 자기 PC로 복사해서 열면 별개 파일이 됩니다.

## HTML 도구 여는 방법

파일을 받아 **더블클릭**하면 기본 브라우저에서 열립니다. 설치·로그인·인터넷 연결이 필요 없고,
사내 PC에서 그대로 동작합니다.

## 화면

| 탭 | 하는 일 |
|---|---|
| **월 달력 · 30%** | 구성원 × 날짜 표. 셀을 눌러 입력. 날짜별 8시간 인원 / 필요 인원을 실시간 판정하고, 미달일에는 **조율 후보**를 뽑아줍니다 |
| **개인 실적 · OT** | 본인 월 총량(소정근로시간) 대비 적립·부족, OT 누적과 잔여, 일별 내역 |
| **탄력근무 52/64** | 대정비(MI·HGPI·CI) 단위기간의 평균 주 52시간 · 개별 주 64시간 판정 |
| **규칙 · 검증기** | "이 근무 조합이 가능한가"를 즉시 확인. 규칙 사전과 자가검증 결과 |
| **설정 · 명부** | 기준값, 공휴일, 구성원 명부 (휴직 체크 시 30% 모수에서 제외) |

## 입력 원칙 — 빈칸이 8시간 근무

현행 엑셀과 같습니다. **8시간을 채우는 사람은 아무것도 입력하지 않고**, 빠지는 사람만 사유를
입력합니다. 달력이 대부분 비어 있는 게 정상입니다.

셀을 누르면 유형(선택근로 · 반차 · 반반차 · 연차 · 출장 · 교육 · 건강검진 …)을 고르고 시간을
넣습니다. 저장 전에 **규칙 위반이면 그 자리에서 이유를 알려줍니다** — 코어타임 미충족, 휴게시간
중합, 최소 근로 3시간 미달, 휴가 블록 배치 불가 등.

달력 셀에는 `11.5h OT2` / `07:30~20:30` 처럼 **근로시간(+OT)과 실제 근무 시각**이 함께 보입니다.

출장·교육처럼 여러 날 이어지는 건 **연속 적용**에 일수를 넣으면 주말·공휴일을 건너뛰고 한 번에
들어갑니다.

### OT 입력

선택적 근로는 30분 단위지만 OT 는 분 단위로 신청하므로, **OT 시작·종료 시각**을 넣으면
시간이 자동 계산됩니다 (`18:00~19:45` → 1.75시간). 자정을 넘겨도 됩니다 (`22:00~01:00` → 3시간).

선택근로 시간과 OT 시간은 **나눠서** 넣습니다. 습관대로 `07:30~22:30` 처럼 한 번에 적으면
**"20:30 이후 2시간을 OT 로 분리"** 버튼이 나타나므로 한 번 누르면 됩니다. OT 시각이 근무
시각과 겹치면 경고합니다.

**석식 휴게**는 정규 근로 종료 직후 30분이고 **실시한 경우에만** 공제합니다. 탄력근무
`08:00~17:00` 에서 OT `17:00~20:00` 을 했다면 석식을 안 먹었으면 3시간, 먹었으면 2.5시간 —
입력할 때 고를 수 있습니다.

OT 한도는 달마다 다르므로 **「개인 실적 · OT」 탭에서 그 달 기본 가능시간을 직접** 넣습니다.
**휴가를 쓰면 그 시간만큼 자동으로 더해집니다** (연차 1일 → +8시간).

### 월 총량

휴가를 쓰면 그만큼 월 총량이 줄어듭니다. 소정 160시간인 달에 연차 1일을 쓰면 **조정 총량이
152시간**이 되고, 실근로 합계를 그 값과 비교합니다.

## 데이터

입력은 **브라우저에 자동 저장**됩니다(같은 PC·같은 브라우저에서 계속 이어집니다).

- **JSON 내보내기 / 불러오기** — 각자 입력한 걸 취합할 때. 불러올 때 *합치기*를 고르면 기존
  데이터를 유지하면서 같은 날짜·구성원만 새 값으로 덮습니다.
- **CSV(엑셀)** — 입력된 건만 긴 형식으로 내보냅니다. 엑셀 피벗으로 집계하거나 기존 양식에
  붙여넣을 때.

> 브라우저 저장은 그 PC에만 남습니다. 취합 담당자를 두고 JSON을 모으거나, 월말에 CSV로 백업하세요.

## 규칙

판정에 쓰는 규칙 전체는 **「규칙 · 검증기」 탭의 규칙 사전**에 그대로 적혀 있고,
근거와 도출 과정은 [`../docs/worktime/DESIGN.md`](../docs/worktime/DESIGN.md) 에 있습니다.

기준값(코어타임, 사용 범위, 30% 비율, OT 한도 등)은 코드가 아니라 **설정 탭**에서 바꿉니다.
규칙이 바뀌면 설정만 고치면 됩니다.

### 자가검증

「규칙 · 검증기」 탭의 **검증 실행**은 실제 운영 사례(가능한 조합과 불가능한 조합 모두)를
규칙에 통과시켜 결과가 일치하는지 확인합니다. 기준값을 바꾼 뒤 여기가 전부 초록인지 보면
의도한 대로 고쳤는지 알 수 있습니다.

## 확인이 필요한 기본값

| 항목 | 현재 값 | 비고 |
|---|---|---|
| 월 OT 한도 | 기본 20시간 | 달마다 다르므로 **개인 탭에서 그 달 한도를 입력** |
| 공휴일 | 2026년 목록 내장 | 설정의 **「연도 추가」** 로 양력 공휴일·대체공휴일 자동 생성. 설날·추석·부처님오신날은 음력이라 직접 입력 |
| 30% 모수 | 명부 24명 − 휴직 1명 = 23명 → 7명 | 명부에서 조정 |
| 30% 판정 단위 | 전체 합산 | 전체 7명 · 그룹별 8명 · 파트별 10명 — 설정에서 전환 가능 |

> 공동 편집이 필요한 작업은 **엑셀**에서 합니다. HTML 도구의 입력은 그 PC 브라우저에만
> 저장되므로 개인 확인·검증 용도로 쓰세요.
