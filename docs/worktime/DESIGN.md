# 근무시간·초과근로 산정 프로젝트 — 설계서 (초안)

> 근태 기록에서 **실근로시간 → 연장·야간·휴일근로시간 → 법정 한도 위반 판정 → 가산수당**까지
> 하나의 계산 엔진으로 산출하는 것을 목표로 한 기획·설계 문서.
> 코드는 아직 없다. 이 문서에서 규칙·데이터 모델·경계를 먼저 확정한 뒤 구현에 들어간다.
>
> ⚠️ 여기 정리한 법령 해석은 설계를 위한 **기준선**이다. 실제 적용 시에는 사업장의 취업규칙·
> 단체협약·노사합의서와 대조하고, 최종 판단은 노무 자문을 거친다.

## 1. 목표 (한 줄)

**근태 기록 입력 → 실행 → 주·월 단위 근로시간 집계 + 주 52시간 위반 판정 + 가산수당 산정 리포트.**

## 2. 범위

| 구분 | 내용 |
|---|---|
| **범위 (In)** | 실근로시간 산정, 연장·야간·휴일근로 구분, 연장근로 한도 위반 판정, 가산수당 산정, 주·월 집계 리포트 |
| **범위 (In, 후속)** | 탄력적·선택적 근로시간제 정산, 보상휴가제(§57) 대체, 주휴수당 |
| **비범위 (Out)** | 급여 전체 계산(4대보험·소득세·공제), 근태 수집 자체(출입기록·지문인식 등 원천 시스템), 연차 관리, 전자결재 연동 |

경계 원칙: **이 툴은 "시간을 판정하는 엔진"이다.** 금액은 통상시급을 외부에서 받아 가산분만 계산하고,
급여 시스템의 역할을 침범하지 않는다.

## 3. 법정 기준 (설계 기준선)

### 3.1 근로시간 한도

| 항목 | 기준 | 근거 |
|---|---|---|
| 소정근로시간 | 1일 8시간, 1주 40시간 | 근로기준법 §50 |
| 연장근로 한도 | 당사자 합의로 **1주 12시간** (→ 주 52시간) | §53① |
| 탄력적 근로시간제 하 연장 | 단위기간 평균 주 40시간 기준 + 12시간 | §51, §51의2, §53② |
| 특별연장근로 | 재난·사고 등, **고용노동부 장관 인가** 필요 | §53④ |
| 특례업종 | 노사 합의 시 12시간 초과 가능, 단 **연속 11시간 휴식** 부여 | §59 |
| 휴게시간 | 4시간 근로 시 30분 이상, 8시간 시 1시간 이상 (근로시간 중) | §54 |
| 주휴일 | 1주 소정근로일 개근 시 유급휴일 1일 | §55, 시행령 §30 |

### 3.2 가산율

| 유형 | 가산 | 근거 |
|---|---|---|
| 연장근로 | 통상임금의 **50% 이상** (총 1.5배 지급) | §56① |
| 야간근로 (22:00~06:00) | **50% 이상** — 연장·휴일과 **중복 가산** | §56③ |
| 휴일근로 8시간 이내 | **50% 이상** | §56②1 |
| 휴일근로 8시간 초과분 | **100% 이상** | §56②2 |

### 3.3 적용 제외·특칙 (엔진이 반드시 분기해야 하는 지점)

| 대상 | 특칙 |
|---|---|
| **상시 5인 미만 사업장** | §53 연장근로 한도, §56 가산수당 **미적용** (§54 휴게·§55 주휴는 적용) — 근로기준법 §11, 시행령 별표1 |
| 관리·감독자, 기밀취급자, 감시·단속적 근로(인가) | 근로시간·휴게·휴일 규정 **미적용** — §63 |
| 18세 미만 연소자 | 1일 7시간·1주 35시간, 연장은 1일 1시간·1주 5시간 한도 — §69 |
| 임신 중 여성 | 연장근로 **금지**, 야간·휴일근로 원칙 금지(인가 필요) — §70②, §74⑤ |
| 산후 1년 미만 | 1일 2시간·1주 6시간·1년 150시간 한도 — §71 |

## 4. 핵심 판단 규칙 — **두 갈래를 분리한다**

이 프로젝트에서 가장 틀리기 쉬운 지점. 한도 위반 판정과 가산수당 산정은 **계산식이 다르다.**

```
(A) 연장근로 한도 위반 판정  ─ 1주 총 실근로시간 기준
    주간초과 = max(0, 주 실근로시간 − 40)
    위반      = 주간초과 > 12
    ※ 대법원 2023도11258 (2024.1.4 선고): 1일 8시간 초과분을 합산하는 방식이 아니라
       1주 총 근로시간이 40시간을 초과한 시간을 기준으로 12시간 한도 위반을 판단.
    ※ 휴일근로시간도 1주 근로시간에 포함 (2018년 개정)

(B) 가산수당 대상 연장근로시간 ─ 1일 8시간 / 1주 40시간, 중복 가산 없이
    일별초과 = Σ_d max(0, 실근로_d − 8)
    주간초과 = max(0, Σ_d 실근로_d − 40)
    연장시간 = max(일별초과, 주간초과)          # 같은 시간을 두 번 세지 않는다
```

즉 **"한도는 안 넘겼는데 가산수당은 발생"** 하는 경우가 정상적으로 존재한다
(예: 월 12시간 + 화~금 각 6시간 = 주 36시간 → 위반 아님, 그러나 가산 대상 연장 4시간).

### 4.1 시간 유형 분해

하나의 근무 구간(출근~퇴근, 휴게 제외)은 아래 축으로 **동시에** 분류된다.

```
실근로 구간
  ├─ 소정근로 / 연장근로        (한 시간은 둘 중 하나)
  ├─ 야간(22:00~06:00) 여부      (연장·휴일과 중복 가산 가능)
  └─ 휴일근로 여부               (휴일이면 연장 가산 대신 휴일 가산율 적용)
```

가산분(통상시급 배수 합계):

```
가산배수 = 연장h × 0.5
         + 야간h × 0.5
         + 휴일_8h이내 × 0.5
         + 휴일_8h초과 × 1.0
가산수당 = 통상시급 × 가산배수
```

> 월급제 근로자는 소정근로분(1.0배)이 월급에 포함되어 있으므로 **연장분은 1.5배 전액**을,
> 시급제는 계산식이 달라진다. 임금 형태(월급제/시급제/포괄임금)를 근로자 속성으로 받는다.

## 5. 데이터 모델 (초안)

```
Workplace     사업장   : id, 상시근로자수, 5인미만여부, 특례업종여부, 소정근로일, 주휴일
Employee      근로자   : id, 사업장, 임금형태(월급/시급), 통상시급, 적용제외구분(§63),
                         연소자/임산부 플래그, 근로시간제(통상/탄력/선택)
Attendance    근태기록 : 근로자, 날짜, 출근시각, 퇴근시각, 휴게시간(분), 휴가·휴일구분, 비고
Holiday       휴일     : 사업장, 날짜, 유형(주휴/법정공휴일/약정휴일)
Agreement     합의     : 사업장, 유형(연장합의/탄력/선택/특별연장인가), 단위기간, 시작~종료
─────────────────────────────────────────────────────────────────
DailyResult   일별결과 : 실근로h, 소정h, 연장h, 야간h, 휴일h, 휴게공제h, 경고
WeeklyResult  주별결과 : 실근로h, 주간초과h, 한도위반여부, 가산배수, 위반사유
PayResult     수당결과 : 기간, 연장·야간·휴일 가산분, 금액, 산출근거(추적 가능한 내역)
```

원칙: **입력(Attendance)은 원본 그대로 보존**하고, 판정 결과는 파생 테이블로 재계산 가능하게 둔다.
법 해석이 바뀌거나 규칙을 고쳤을 때 원본을 재계산해서 차이를 볼 수 있어야 한다 (기존 `verify` 패턴과 동일).

## 6. 계산 파이프라인

```
[입력] 근태기록 (근로자 × 날짜 × 출퇴근시각 × 휴게)
   │
   ▼ normalize        # 자정 넘김(익일 퇴근) 분할, 결측·역전(퇴근<출근) 검증
[정규화 구간]
   │
   ▼ break_rule       # §54 휴게 최소 충족 검사 + 실근로 = 체류 − 휴게
[일별 실근로시간]
   │
   ▼ classify         # 야간(22~06) 교집합, 휴일 여부 태깅, 일 8시간 초과분
[일별 유형 분해]
   │
   ▼ weekly_aggregate # 주 단위 합산 (주 시작요일은 사업장 설정)
[주별 집계]
   │
   ├─▶ limit_check    # (A) 주 40시간 초과분 > 12h → 위반 · §63/5인미만/연소자 분기
   └─▶ premium        # (B) max(일별초과, 주간초과) → 가산배수 → 금액
   │
   ▼ report
[출력] 주·월 집계표 + 위반 목록 + 가산수당 내역 (산출근거 포함)
```

## 7. 아키텍처 제안

기존 `tool/wirye_capacity` 와 같은 패턴(순수 계산 코어 + 얇은 입출력 계층 + 골든 케이스 회귀)을 재사용한다.

```
worktime/
├─ worktime/
│  ├─ constants.py      # 법정 기준값 (40/8/12, 22:00~06:00, 가산율, 휴게 문턱)
│  ├─ rules.py          # 법령 규칙을 데이터로 (버전·시행일별 규칙 세트)
│  ├─ normalize.py      # 자정 넘김 분할·결측·역전 검증
│  ├─ classify.py       # 야간·휴일·일 8시간 초과 분해
│  ├─ aggregate.py      # 주·월 집계 (주 시작요일 설정)
│  ├─ limits.py         # (A) 한도 위반 판정 + 적용제외 분기
│  ├─ premium.py        # (B) 가산배수·가산수당
│  ├─ flexible.py       # 탄력·선택 근로시간제 정산 (후속)
│  ├─ report.py         # 집계표·위반목록·내역 출력
│  ├─ io/               # ← 입력 계층 (§8, 미정)
│  └─ cli.py            # CLI 진입점
└─ tests/               # 골든 케이스 회귀
```

`rules.py` 를 **시행일 버전 단위**로 분리하는 것이 핵심 설계 결정이다. 법·판례가 바뀌면
계산 코드가 아니라 규칙 데이터만 추가하고, 과거 기간은 과거 규칙으로 재계산되어야 한다.

## 8. 입력 계층 — **미정 (결정 보류)**

사용자 확정: *"우선 계산 로직만 만들고 입력 계층은 나중에 결정"*.
따라서 코어는 **입력 형태를 모르는 상태**로 구현한다 — `io/` 아래 어댑터만 갈아끼우면 되도록.

| 후보 | 장점 | 비용 | 비고 |
|---|---|---|---|
| 엑셀 근태파일 (xlsx) | 사내 근태 시스템 다운로드본 그대로 | 회사별 열 구조 매핑 필요 | 기존 repo `excel_io` 패턴 재사용 가능 |
| CSV / CLI 직접 입력 | 가장 단순, 테스트·검증에 최적 | 실무 투입 시 변환 수작업 | **Phase 1의 기본 입력으로 채택** |
| GUI 표 입력·편집 | 소규모 사업장에 바로 사용 가능 | UI 비용 | 기존 `ui/app.py`(PySide6) 패턴 |

**결정 규칙**: 코어 함수는 `Attendance` 데이터클래스 리스트만 받는다. 어떤 어댑터가 그것을
만들었는지 코어는 알지 않는다. 입력 형태 결정은 Phase 3까지 미뤄도 코어 진행에 지장이 없다.

## 10. 검증 전략

계산 결과가 맞는지 스스로 주장할 수 없는 도메인이므로, **외부 근거가 있는 케이스만** 정답으로 삼는다.

1. **고용노동부 해설서·질의회시 예시** — 공표된 계산 예제를 그대로 케이스화
2. **판례 사례** — 특히 §4의 (A)/(B) 분리를 검증하는 대법원 2023도11258 사실관계
3. **경계 케이스** — 자정 넘김 근무, 휴일 + 야간 + 8시간 초과 중복, 주 시작요일 변경,
   휴게 미부여, 결측·역전 기록, 5인 미만 사업장, 주 40시간 미달인데 일 8시간 초과
4. **역방향 검산** — 가산배수 합계 × 통상시급 = 수당 총액, 유형별 시간 합 = 실근로시간

각 케이스는 "입력 → 기대값 → 근거 출처"를 한 줄로 명시해 회귀 테스트에 고정한다.

## 11. 미결정 사항 (구현 전 확인 필요)

| # | 질문 | 영향 |
|---|---|---|
| 1 | 대상 사업장이 **상시 5인 이상**인가? | 5인 미만이면 §53 한도·§56 가산수당 자체가 미적용 → 엔진의 절반이 무의미 |
| 2 | 근로시간제가 **통상 / 탄력 / 선택** 중 무엇인가? | 주 40시간 기준선과 정산 단위가 바뀜 |
| 3 | 임금 형태가 **월급제 / 시급제 / 포괄임금제** 중 무엇인가? | 연장분을 1.5배 전액으로 볼지 0.5배 가산만 볼지 결정 |
| 4 | **주의 시작 요일**과 급여 정산 기간(월 시작일)은? | 주별 집계 경계가 결과를 바꿈 |
| 5 | 휴게시간이 근태기록에 **기록되어 있는가**, 아니면 규정값으로 공제하는가? | `break_rule` 의 입력 유무 |
