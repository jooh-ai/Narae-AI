## 내 앞선 설명을 정정한다 — CIT 소수점 규약

CSV 의 기존 5회차를 씨앗과 대조하니 **불일치 0건**이었다(CIT·대기압·RH·CC·진공도 전부).
씨앗의 CIT 는 전부 1 소수점이고 CSV 도 1 소수점이다.

즉 이 프로젝트의 데이터 정본 규약은 **담당자 Base Load 실적표 전사값(1 소수점)** 이다.
산정 탭이 보여주는 `37.92` 는 Tool 자동 취득값(2 소수점)이고, 두 경로가 공존한다.

| | CIT | 이론 | 보정값 |
|---|---|---|---|
| 담당자 표 전사 (씨앗·CSV 규약) | 37.9 | 359.78 | **+1.42** |
| Tool 자동 취득 (산정 탭·DB) | 37.92 | 359.72 | **+1.48** |

내가 앞서 *"누적에 저장되는 값은 산정 탭 쪽"* 이라고 한 것은 **DB 기준**이었고,
**장표 데이터의 정본은 담당자 표 쪽**이다. 0.06 MW 차이는 여기서 온다.

→ **정해야 할 사항**: 어느 쪽을 정본으로 삼는가. 씨앗이 이미 1 소수점이므로
담당자 표 쪽으로 통일하는 것이 일관되고, 그러면 시뮬레이션 탭 값이 정본이 된다.
(내가 "시뮬 탭 반올림 버그" 라고 부른 것은 **버그가 아니라 규약 차이**였다.)
