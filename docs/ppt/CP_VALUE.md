# 공급가능용량 예측 개선의 금액 효과 — 검토와 우리 케이스 대입

받은 자료 두 건을 대조해 검토하고, 우리 데이터(누적 40회)에 대입했다.
계산은 `docs/ppt/build/cp_value.py` 로 재현된다.

---

## 1. 자료 ①「CP 정산 기준」 — 우리 주장을 규칙이 뒷받침한다

정산식(전력시장운영규칙 [별표 2], 복합발전기)

```
TPCP(i,t) = Min( TA, RA, Max(MGO, FCA) ) × (HCF + β) × 1,000
HCF       = RCP × RCF × TCF × PCF
```

**핵심은 `Min()` 이고, 이 구조 때문에 신고 방향에 따라 결과가 비대칭이다.**

| 신고 방향 | 병목이 되는 항 | 결과 |
|---|---|---|
| **낮게** 신고 (TA < 실제) | **TA** | 낼 수 있었던 (실제 − TA) 만큼 용량요금을 **못 받는다** → 금액으로 환산되는 직접 손실, **회수 가능** |
| **높게** 신고 (TA > 실제) | `Max(MGO, FCA)` | **용량요금은 실제만큼만 나온다.** 높게 신고해도 CP 는 늘지 않는다 → 늘어나는 것은 기준 미달 위험뿐 |

> 이 비대칭이 이번 검토의 가장 중요한 발견이다. 발표자료 4장의 "어느 쪽으로
> 틀려도 손실" 은 맞지만, **손실의 성질이 양쪽에서 다르다.**
> 낮게 신고 = 받을 돈을 못 받음 / 높게 신고 = 돈은 안 늘고 위험만 늘어남.

또한 복합발전기는 기온에 따른 출력변동을 인정받아 **기상예보 갱신에 따른
공급가능용량(TA)** 을 쓸 수 있다. 즉 이 과제가 정확하게 만든 값이 정산식의
첫 번째 인자로 그대로 들어간다.

## 2. 자료 ②「30일 명세서 분석」 — 맞는 것과 고쳐야 할 것

### ✅ 맞는 것 — 단가 계산은 정확하다 (검산 완료)

```
HCF ≈ RCP 11,580 × RCF 0.9067 = 10,499.6 원/MW·h   (자료의 10,497 과 일치, 반올림 차이)
10,499.6 × 8,760h = 91,977,000원  ≈  9,200만원 / MW·년   ✅
```

### ⚠ 고쳐야 할 것 세 가지

**① 에너지수익 6.7억원/MW 는 이 과제의 효과가 아니다 — 가장 큰 문제**

- **실발전량은 중앙급전 지시로 정해진다.** 공급가능용량을 1 MW 더 정확히
  신고했다고 1 MW 더 발전하는 것이 아니다. 정확한 신고가 직접 바꾸는 것은
  **용량요금**이다.
- **`SMP × MWh` 는 매출이지 이익이 아니다.** LNG 복합의 변동비(연료비)를 빼지
  않은 값이다. 급전 발전기의 SMP 는 한계 발전기의 변동비에 수렴하므로 이
  마진은 매출의 일부에 불과하다.
- 따라서 "합산 7.6억원/MW·년" 은 **용량요금 9,200만원에 성질이 다른 매출을
  더한 값**이다. 본사 보고에서 이 숫자를 쓰면 반드시 반박당한다.

**② `Min()` 구조가 반영되지 않았다**

자료 ②는 "과대신고 패널티 방지" 를 이득으로 계상했다. 그런데 자료 ①의 식대로면
**높게 신고해도 CP 는 실제만큼만 나온다.** 과대 신고를 줄인 것은 CP 증가가
아니라 **미달 위험 감소**다. 금액으로 쓰려면 페널티 단가가 따로 필요하다.
두 자료를 같이 읽지 않으면 같은 개선을 두 번 세게 된다.

**③ 자료 안에서 결론이 서로 다르다**

4항 표는 "연간 누적 **약 5~8억원**", 6항 결론은 "**약 15~23억원**" 이다.
같은 문서에서 3배 차이가 난다. 어느 쪽도 산출 과정이 적혀 있지 않다.

## 3. 우리 케이스 대입 — 방어 가능한 값

**금액이 되는 것은 '낮게 신고한 양' 하나다.** 우리 데이터에 그 값이 있다
(`impact.*.opp` — 실제가 신고값을 넘었을 때 그 초과분의 누계).

| | 종전 방식 | 현재 도구 |
|---|---|---|
| 낮게 신고한 양 누계 (39회 채점) | 75.3 MW | 30.6 MW |
| **회당 평균** | **1.93 MW** | **0.78 MW** |
| 연 환산 CP 손실 | **1.78억원/년** | **0.72억원/년** |

### → 회수 효과 = 연 약 **1.05억원** (회당 1.15 MW)

민감도 — CP 적용시간 가정을 흔들어도 크게 변하지 않는다.

| 연간 적용시간 비율 | 회수 효과 | 비고 |
|---|---|---|
| 1.00 | **1.05억원/년** | 8,760h 전부 (상한) |
| 0.92 | 9,700만원/년 | 정비 4주 제외 |
| 0.85 | 8,960만원/년 | 정비·불시정지 포함 |
| 0.70 | 7,380만원/년 | 보수적 |

**별도로 계상하지 않은 효과** (금액 환산에 자료가 더 필요하다)

- 기준 미달 **15회 → 4회**, 과대 신고 누계 69.5 → 9.3 MW
  → 페널티·신뢰도계수(RCF) 리스크 감소. **페널티 단가를 받으면 환산 가능.**
- Base Load Test 횟수 절감 → 연료비·인력 절감. 시험 1회 비용이 필요하다.
- 담당자 업무 시간 절감(엑셀 4개 → 도구 1개) → 시간당 인건비가 필요하다.

## 4. 계산에 쓴 전제 — 확인이 필요한 것

| # | 전제 | 지금 값 | 왜 중요한가 |
|---|---|---|---|
| T1 | 신고(TA) 갱신 주기 | 회차가 1년을 덮는다고 가정 (40회 / 약 14개월 = 10.4일마다) | 한 번 신고가 며칠 적용되는지가 연 환산의 뼈대다 |
| T2 | TCF (시간대별 계수) | **1.0 가정** | 시간대별로 다르면 실효 단가가 달라진다. 명세서에서 `총 용량요금 ÷ 총 인정용량·시간` 으로 **역산하면 가정이 필요 없다** |
| T3 | PCF (성과연동 계수) · β | **1.0 / 0 가정** | 위와 같다 |
| T4 | 연간 CP 적용시간 | 8,760h 전부 | 정비·정지 기간을 빼면 위 민감도 표대로 줄어든다 |
| T5 | 기준 미달 페널티 단가 | **미수령** | 있으면 '높게 신고' 쪽도 금액이 된다 |

> **T2·T3 이 가장 값이 크다.** 명세서에 월 총 용량요금과 인정용량이 있으면
> 실효 단가를 역산할 수 있고, 그러면 RCP·RCF·TCF·PCF·β 를 하나도 가정하지
> 않아도 된다. 그 값을 주시면 위 표를 다시 계산한다.

## 5. 발표자료 반영안

지금 4장 결론은 "정확도가 곧 **손익**입니다" 로, 금액 없이 두었다. 위 값을
넣으면 다음처럼 바꿀 수 있다.

| 장 | 넣을 문구(안) |
|---|---|
| 3장 요약 | 지표 옆 한 줄 — "낮게 신고해 못 받던 용량요금 **연 1.8억 → 0.7억원**" |
| 4장 | 그래프 아래 — "낮게 신고한 만큼은 용량요금으로 받지 못합니다. 종전 회당 1.9 MW = **연 1.8억원**" / 결론 "정확도가 곧 **용량요금**입니다" |
| 11장 효과 | ③ 항목 신설 — "용량요금 회수 **연 약 1.0억원**" + 산출 조건 주석 |

> **주석은 반드시 붙인다** — "용량요금(CP) 기준. 에너지수익은 급전 지시로
> 정해지므로 포함하지 않음. HCF = RCP 11,580 × RCF 0.9067, 적용시간 8,760h 가정."
> 근거 없는 숫자로 보이면 이 장 전체의 신뢰가 떨어진다.
