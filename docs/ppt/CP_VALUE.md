# 공급가능용량 예측 개선의 금액 효과 — 검토와 우리 케이스 대입

받은 자료 두 건을 대조해 검토하고, 우리 데이터(누적 40회)에 대입했다.
계산은 `docs/ppt/build/cp_value.py` 로 재현된다.

---

## 1. 자료 ①「CP 정산 기준」 — 우리 주장을 규칙이 뒷받침한다

정산식(전력시장운영규칙 [별표 2], 복합발전기)

```
TPCP(i,t) = Min( TA, RA, Max(MGO, FCA) ) × (HCF + β) × 1,000
HCF       = RCP × RCF × TCF × PCF
```

**핵심은 `Min()` 이고, 이 구조 때문에 신고 방향에 따라 결과가 비대칭이다.**

| 신고 방향 | 병목이 되는 항 | 결과 |
|---|---|---|
| **낮게** 신고 (TA < 실제) | **TA** | 낼 수 있었던 (실제 − TA) 만큼 용량요금을 **못 받는다** → 금액으로 환산되는 직접 손실, **회수 가능** |
| **높게** 신고 (TA > 실제) | `Max(MGO, FCA)` | **용량요금은 실제만큼만 나온다.** 높게 신고해도 CP 는 늘지 않는다 → 늘어나는 것은 기준 미달 위험뿐 |

> 이 비대칭이 이번 검토의 가장 중요한 발견이다. 발표자료 4장의 "어느 쪽으로
> 틀려도 손실" 은 맞지만, **손실의 성질이 양쪽에서 다르다.**
> 낮게 신고 = 받을 돈을 못 받음 / 높게 신고 = 돈은 안 늘고 위험만 늘어남.

또한 복합발전기는 기온에 따른 출력변동을 인정받아 **기상예보 갱신에 따른
공급가능용량(TA)** 을 쓸 수 있다. 즉 이 과제가 정확하게 만든 값이 정산식의
첫 번째 인자로 그대로 들어간다.

## 2. 자료 ②「30일 명세서 분석」 — 맞는 것과 고쳐야 할 것

### ✅ 맞는 것 — 단가 계산은 정확하다 (검산 완료)

```
HCF ≈ RCP 11,580 × RCF 0.9067 = 10,499.6 원/MW·h   (자료의 10,497 과 일치, 반올림 차이)
10,499.6 × 8,760h = 91,977,000원  ≈  9,200만원 / MW·년   ✅
```

### ⚠ 고쳐야 할 것 세 가지

**① 에너지수익 6.7억원/MW 는 이 과제의 효과가 아니다 — 가장 큰 문제**

- **실발전량은 중앙급전 지시로 정해진다.** 공급가능용량을 1 MW 더 정확히
  신고했다고 1 MW 더 발전하는 것이 아니다. 정확한 신고가 직접 바꾸는 것은
  **용량요금**이다.
- **`SMP × MWh` 는 매출이지 이익이 아니다.** LNG 복합의 변동비(연료비)를 빼지
  않은 값이다. 급전 발전기의 SMP 는 한계 발전기의 변동비에 수렴하므로 이
  마진은 매출의 일부에 불과하다.
- 따라서 "합산 7.6억원/MW·년" 은 **용량요금 9,200만원에 성질이 다른 매출을
  더한 값**이다. 본사 보고에서 이 숫자를 쓰면 반드시 반박당한다.

**② `Min()` 구조가 반영되지 않았다**

자료 ②는 "과대신고 패널티 방지" 를 이득으로 계상했다. 그런데 자료 ①의 식대로면
**높게 신고해도 CP 는 실제만큼만 나온다.** 과대 신고를 줄인 것은 CP 증가가
아니라 **미달 위험 감소**다. 금액으로 쓰려면 페널티 단가가 따로 필요하다.
두 자료를 같이 읽지 않으면 같은 개선을 두 번 세게 된다.

**③ 자료 안에서 결론이 서로 다르다**

4항 표는 "연간 누적 **약 5~8억원**", 6항 결론은 "**약 15~23억원**" 이다.
같은 문서에서 3배 차이가 난다. 어느 쪽도 산출 과정이 적혀 있지 않다.

## 3. 우리 케이스 대입 — 방어 가능한 값

### 단가 (2026-09-07 확정)

```
150 원/kW·일  ×  입찰일 335일 (365 − 정비 30일 ≈ 11개월)  =  5,025만원 / MW·년
```

- **입찰한 날에만 받는다.** 정비 기간에는 입찰이 0 이므로 CP 도 0 이다.
  연간 30일 정비를 가정해 **335일**로 잡았다.
- 단위는 **원/kW·일** 이다. '월' 로 읽으면 150 × 11 = 165만원/MW·년인데
  명세서 기준(252원/kW·일 = 7,560원/kW·월)의 **1/50** 이라 앞뒤가 맞지 않는다.
- **교차검증** — 명세서 기준 `RCP 11,580 × RCF 0.9067 = 252원/kW·일` 과 비교하면
  정본은 그 **60%** 다. 차이는 시간대별 계수(TCF)·성과계수(PCF)로 보이며,
  정본 쪽이 더 보수적이다. **보고에는 보수적인 값을 쓴다.**

### 계산

**금액이 되는 것은 '낮게 신고한 양' 하나다** (`impact.*.opp` — 실제가 신고값을
넘었을 때 그 초과분의 누계).

| | 종전 방식 | 현재 도구 |
|---|---|---|
| 낮게 신고한 양 누계 (39회 채점) | 75.3 MW | 30.6 MW |
| **회당 평균** | **1.93 MW** | **0.78 MW** |
| 연 환산 CP 손실 | **9,702만원/년** | **3,943만원/년** |

### → 회수 효과 = 연 약 **5,800만원** (회당 1.15 MW)

### 민감도

| 정비 일수 | 입찰일 | 연간 회수 | | 단가 | 연간 회수 |
|---|---|---|---|---|---|
| 0일 | 365일 | 6,275만원 | | 120원/kW·일 | 4,608만원 |
| 15일 | 350일 | 6,017만원 | | **150원/kW·일** | **5,759만원** |
| **30일** | **335일** | **5,759만원** | | 200원/kW·일 | 7,679만원 |
| 45일 | 320일 | 5,502만원 | | 252원/kW·일 (명세서) | 9,676만원 |
| 60일 | 305일 | 5,244만원 | | | |

**정비 일수는 결과를 거의 바꾸지 않는다**(0~60일에서 5,244~6,275만원, ±9%).
**단가가 지배적**이다 — 150원이면 5,800만원, 명세서 기준 252원이면 9,700만원.

**별도로 계상하지 않은 효과** (금액 환산에 자료가 더 필요하다)

- 기준 미달 **15회 → 4회**, 과대 신고 누계 69.5 → 9.3 MW
  → 페널티·신뢰도계수(RCF) 리스크 감소. **페널티 단가를 받으면 환산 가능.**
- Base Load Test 횟수 절감 → 연료비·인력 절감. 시험 1회 비용이 필요하다.
- 담당자 업무 시간 절감(엑셀 4개 → 도구 1개) → 시간당 인건비가 필요하다.

## 4. 전제 — 확정된 것과 남은 것

### ✅ 확정 (2026-09-04 확인)

**T1 · 신고 주기 — 계산의 뼈대가 가정이 아니라 실제와 맞았다**

- 공급가능용량 테스트는 **2주마다** 한다. 한 번의 테스트로 얻은 보정값을
  **2주 동안** 쓴다 (14일 × 24h = 336h).
- 그 2주 안에는 **매일 대기압만 다시 보정해** 용량을 산정하고 **매일 입찰**한다.

> 즉 **대기압 오차는 매일 갱신되어 줄지만, 온도별 보정값의 오차는 2주 내내
> 고정된다.** 이 과제가 고치는 것이 바로 그 고정 오차다 — 그래서 오차 1 MW 가
> 336시간 동안 그대로 CP 에 반영된다.
>
> 연간 26.1회 × 336h = **8,736h (8,760h 의 99.7%)**. 따라서 §3 의
> '회당 평균 × 8,760h' 는 **가정이 아니라 실제 운영 주기와 일치**한다.

**T-에너지 · 에너지수익은 계상하지 않는다** — §2 ① 의 이유로 확정.

### ⏳ 남은 것

| # | 전제 | 지금 값 | 상태 |
|---|---|---|---|
| **T2·T3** | 실효 단가 (TCF·PCF·β 포함) | **150원/kW·일** | ✅ **2026-09-07 확정** — 사용자 제시. 명세서 기준(252원)의 60%로 보수적 |
| **T4** | 연간 CP 적용일 | **335일** (365 − 정비 30일) | ✅ **2026-09-07 확정** — 입찰한 날에만 받는다 |
| T5 | 기준 미달 페널티 단가 | **미수령** | ⏳ 있으면 '높게 신고' 쪽도 금액이 된다 |

> **150원은 "정확하게는 계산을 해야겠지만" 이라는 단서가 붙은 계획값이다.**
> 명세서에서 **① 월 총 용량요금(원) ÷ ② 그 달 총 인정용량·시간(MW·h)** 으로
> 역산하면 확정된다. 그때는 `cp_value.py` 의 `RATE_KW_DAY` 한 줄만 고치면
> 문서와 발표자료 수치가 함께 갱신된다.

### 한 가지 모델링 유의점

`opp`(낮게 신고한 양)는 각 테스트 **당시 조건**에서 계산한 값이다. 실제로는
2주 동안 대기압이 변하고 매일 재산정되므로 그날그날의 실제 격차는 조금씩
다르다. 여기서 쓴 회당 평균은 **2주 내내 고정되는 보정값 오차**의 대표값으로
본 것이다 — 대기압 성분은 매일 갱신되어 상쇄되므로 이 근사가 타당하다.

## 5. 발표자료 반영안

단가와 적용일이 확정됐으므로 넣을 수 있다. 아래 문구로 반영한다.

지금 4장 결론은 "정확도가 곧 **손익**입니다" 로, 금액 없이 두었다. 위 값을
넣으면 다음처럼 바꿀 수 있다.

| 장 | 넣을 문구 |
|---|---|
| 3장 요약 | 하단 주석에 한 줄 — "낮게 신고해 못 받던 용량요금 **연 9,700만 → 3,900만원**" |
| 4장 | 그래프 아래 — "낮게 신고한 만큼은 용량요금으로 받지 못합니다. 종전 회당 1.9 MW = **연 9,700만원**" / 결론 "정확도가 곧 **용량요금**입니다" |
| 11장 효과 | 정확도 항목에 한 줄 — "용량요금 회수 **연 약 5,800만원**" |

> **주석은 반드시 붙인다** — "용량요금(CP) 기준 · 150원/kW·일 × 입찰일 335일
> (정비 30일 제외). 에너지수익은 급전 지시로 정해지므로 포함하지 않음."
> 근거 없는 숫자로 보이면 이 장 전체의 신뢰가 떨어진다.
