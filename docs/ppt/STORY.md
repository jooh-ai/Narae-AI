## 2. 스토리 한 줄

> **"2주마다 엑셀 4개를 돌려 61개 온도를 신고했는데, 온도마다 다르게 틀렸다.
> 원인은 온도 하나였고, 이론식은 그대로 둔 채 온도별 차이만 배우게 해서
> 도구로 만들었다. 오차가 3분의 1로 줄었고, 테스트가 쌓일수록 더 줄고 있다."**

### 각 장이 다음 장에 넘기는 질문

```
①  엑셀 4개로 만들었다. 보정값은 하나였다.        →  하나로 맞던가?
②  온도마다 다르게 틀렸다. +13 ~ −5 MW.           →  왜 그런가?
③  원인은 온도 하나였다.                           →  그럼 어떻게 고치나?
④  이론은 그대로, 온도별 차이만 배웠다.            →  그래서 뭐가 달라졌나?
⑤  도구가 알아서 하고, 테스트마다 갱신된다.        →  효과가 얼마인가?
⑥  오차 3.9 → 1.3 MW. 연 5,800만원.               →  앞으로는?
⑦  쌓일수록 좋아진다. 다른 사업소에도 된다.
```

## 3. 장별 구성 (본문 10장)

기호 — 📷 실물 캡처 / 📊 우리가 그린 차트 / 🔢 큰 숫자

### 1. 표지
그대로 둔다(회사 CI · 제목 · 소속 · 작성자 · 일자). **손대지 않는다.**

### 2. 목차
7항목 + 쪽번호. 지금 것 그대로. **10초**.

### 3. ① 개요 및 추진 배경 — **종전에는 이렇게 했다**  📷
- **가운데에 엑셀 캡처를 크게** (`xl_profile.png`)
- 위에 4칸 흐름: `RiMS 데이터 → 엑셀① 정리 → 엑셀② 계산 → 엑셀③ 온도 프로파일 → 신고`
- 아래 한 줄: **"테스트는 한 점, 신고는 61개 온도 전부.
  그 빈 구간을 메우려고 보정값 하나를 61개에 똑같이 적용했습니다."**
- 작게 곁들임: 수식 보기 캡처(`xl_formula.png`) — 시트끼리 물려 있는 모습

> 담당자를 탓하는 자리가 아니다. **"그때는 그게 최선이었다"** 를 분명히 한다.

### 4. ② 현황 파악 및 문제 정의 — **온도마다 다르게 틀렸다**  📊
- 산점도 하나만 크게 (온도축 · 보정값). 점 40개.
- 겨울(+13) 과 여름(−5) 두 곳만 표시. 나머지 주석 없음.
- 한 줄: **"겨울엔 13 MW 더 나오고, 여름엔 5 MW 덜 나왔습니다."**

### 5. ③ 데이터 분석 및 원인 규명 — **원인은 온도 하나**  📊
- **표를 쓰지 않는다.** 후보 4개를 가로로 놓고, 온도만 남기는 그림 한 장.
- 한 줄: **"진공도·대기압·습도를 넣어봤지만 예측이 나아지지 않았습니다."**
- 숫자는 **딱 하나만** — "온도 하나로 갈림의 85% 가 설명됩니다."
- 표(RMSE·MAE·R²·AIC)는 **부록 A1** 로 내린다

### 6. ④ 해결 방안 · 모델 개발 — **이론은 그대로, 차이만 배운다**  📷
- **도구의 출력곡선 캡처를 크게** (`tool_curve.png` 위 절반)
  점선 = 이론, 주황 = 실제. 두 선이 벌어지는 그림 자체가 설명이다.
- 왼쪽에 2층 그림: `① 이론식 — 손대지 않음` / `② 온도별 차이 — 40회로 학습`
- 한 줄: **"검증된 이론식은 그대로 두고, 이론과 실제의 차이만 배우게 했습니다."**
- 커널·GP 이야기는 **부록 A2**

### 7. ⑤ 향후 추이 분석 · 모니터링 — **도구가 알아서 갱신한다**  📷
- **도구 캡처 2장** — 산정 화면(`tool_input.png`) + 누적 목록(`tool_list.png`)
- 순환 4칸: `테스트 → 도구에 입력 → 곡선 갱신 → 다음 신고에 반영`
- 한 줄: **"테스트를 한 번 할 때마다 도구가 스스로 다시 배웁니다."**
- 여기서 **시연**으로 넘어간다(3~4분)

### 8. ⑥ 개선 효과 — **결과**  🔢📊
- 큰 숫자 3개를 화면 위쪽에 크게
- 아래에 **성공 사진**: 도구의 보정값 곡선 + 실측점이 예측 범위 안에 들어온 그림
  (`tool_curve.png` 아래 절반) — **"우리가 그은 선 안에 실제가 들어왔습니다."**
- 금액 한 줄: 용량요금 기준 · 조건 명시

### 9. ⑦ 향후 계획 · 수평 전개 — **쌓일수록 좋아진다**  📊
- **학습 곡선**(회차가 늘수록 오차가 줄어든 실제 그래프)을 크게
- 한 줄: **"테스트는 계속합니다. 회차가 쌓이면 예측은 더 정확해집니다."**
- 오른쪽에 전개 3단계(위례 정착 → 같은 구조 사업소 → 표준화)

### 10. 마무리
「감사합니다」 + 출력 곡선 + 실측 40회. 지금 것 유지.

## 5. 말투 규칙 — 'AI 느낌' 을 없애는 실제 조치

| 하지 않을 것 | 대신 |
|---|---|
| 제목에 줄표(—)로 두 구를 잇기 | **짧은 단정문 한 줄.** "원인은 온도 하나" |
| "~했습니다" 대구를 장마다 반복 | 장마다 어미를 바꾼다. 명사형도 쓴다 |
| 카드 3개를 매 장 반복 | 장마다 구성을 다르게 (2칸·4칸·그림 한 장) |
| 한 장에 설명 문장 5줄 이상 | **최대 3줄**, 각 줄 40자 이내 |
| 수치 옆에 매번 설명 붙이기 | 큰 숫자는 숫자만. 설명은 말로 한다 |
| 완곡어("~인 것으로 보입니다") | 단정하거나, 모르면 모른다고 |

**분량 상한** — 제목 24자 / 리드 45자 / 그림이 본문 면적의 2/3 이상 / 장당 낱말 80개 이하.
