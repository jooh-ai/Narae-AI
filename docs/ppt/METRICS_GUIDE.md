# 6장 표의 네 지표 — 무슨 숫자인가

> 발표 전 Q&A 대비용. 6장 표(`varsel.compare`)의 RMSE · MAE · R² · AIC 를
> 통계 배경 없이 읽을 수 있게 풀어 둔다. 수치는 누적 40회 · 채점 39회 기준.

## 0. 먼저 — 네 지표는 **같은 39개 숫자**를 다르게 요약한 것이다

채점 방식은 하나뿐이다.

```
40회 중 1회를 가린다  →  남은 39회로 곡선을 다시 학습한다
                      →  가린 회차의 보정값을 맞혀 본다
                      →  오차 = (실제 보정값) − (맞힌 값)     ← MW 단위
39회 전부 돌리면 오차 39개가 나온다        (= LOOCV)
```

**RMSE · MAE · R² 는 이 오차 39개를 각각 다르게 요약한 값이다.**
AIC 만 계보가 다르다 — 오차가 아니라 '데이터에 얼마나 잘 맞았는가'
에서 계산하고, 변수를 늘린 만큼 벌점을 뺀다.

이 판의 기준선을 먼저 알아 두면 모든 숫자가 쉬워진다.

| 기준선 | 값 | 뜻 |
|---|---|---|
| 채점 39회 보정값 | 평균 **+2.45 MW**, 범위 **−4.86 ~ +12.95 MW** | 우리가 맞혀야 하는 대상 |
| 그 흩어진 폭(표준편차) | **4.39 MW** | 아무것도 안 배웠을 때의 오차 크기 |
| 종전 일괄보정 | MAE **3.90** · RMSE **4.50** | 값 하나(+2.46)를 61개 온도에 그대로 |
| 현재 도구 | MAE **1.30** · RMSE **1.68** | 온도별 곡선 |

> **종전 일괄보정의 R² 는 −0.05, 사실상 0 이다.** 일괄보정 값(+2.46)이 39회
> 평균(+2.45)과 거의 같으니 당연하다 — **"평균 하나를 쓴 것"과 통계적으로
> 같은 자리**에 있었다는 뜻이다. 우리 모델은 같은 자에서 0.854 다.

---

## 1. MAE — "평균 몇 MW 틀리나"

```
MAE = (|오차1| + |오차2| + … + |오차39|) ÷ 39
```

가장 직관적이다. **단위가 그대로 MW** 이고, 부호를 없앤 뒤 평균만 낸다.
`MAE 1.301` = 신고할 값을 미리 계산해 두면 **평균 1.3 MW 어긋난다**.

- 작을수록 좋다.
- 오차 10개가 각각 1 MW 인 경우와, 9개가 0 이고 1개가 10 MW 인 경우가
  **MAE 로는 똑같다.** 이 약점을 메우는 것이 RMSE 다.

## 2. RMSE — "크게 틀린 회차에 벌점을 더 준 오차"

```
RMSE = √( (오차1² + 오차2² + … + 오차39²) ÷ 39 )
```

제곱을 먼저 하므로 **큰 오차가 훨씬 무겁게 반영된다.** 5 MW 틀린 한 회가
1 MW 틀린 다섯 회보다 나쁘게 채점된다. 입찰에서는 이게 맞는 관점이다 —
평소 잘 맞다가 한 번 크게 미달하는 쪽이 위험하다.

- 단위도 MW 다. **항상 RMSE ≥ MAE** 이고, 둘의 비율이 오차 모양을 알려준다.

| RMSE ÷ MAE | 뜻 |
|---|---|
| 1.0 | 모든 회차가 똑같은 크기로 틀렸다 |
| 약 1.25 | 오차가 정규분포에 가깝게 흩어졌다 (정상) |
| 1.5 이상 | **가끔 크게 틀리는 회차가 있다** — 경계해야 한다 |

우리 표는 다섯 모델 모두 **1.27 ~ 1.32** 다. 특정 모델이 "평소엔 좋은데
가끔 크게 터진다" 는 문제를 안고 있지 않다는 뜻이다.

## 3. R² — "아무것도 안 배웠을 때보다 얼마나 줄였나"

```
R² = 1 − (모델 오차)² ÷ (아무것도 안 배웠을 때의 오차)²
```

보정값은 회차마다 −4.86 ~ +12.95 MW 로 갈리고, 그 흩어진 폭이 **4.39 MW** 다.
평균(+2.45)만 쓰면 오차가 그 4.39 MW 다 — **이 자리가 R² = 0** 이다.

```
R² = 1 − (1.678 ÷ 4.39)²  =  1 − 0.146  =  0.854
```

**`R² 0.854` = 회차마다 갈리는 폭의 85.4% 를 온도로 설명했고, 14.6% 가 남았다.**

- 1 에 가까울수록 좋다. 0 이면 평균만 쓰는 것과 같고, **음수면 평균보다 못하다**.
- R² 순위는 **RMSE 순위와 항상 같다** — 같은 채점집합이라 분모가 동일하기
  때문이다(`select.py` 주석). 그래서 두 지표를 '독립된 두 근거' 로 말하면 안 된다.

## 4. AIC — "성적 대비 몸값이 맞나"

```
AIC = 2k − 2·lnL       k   = 하이퍼파라미터 수 = (변수 수) + 2
                       lnL = 데이터에 얼마나 잘 맞았는가 (클수록 잘 맞음)
```

앞의 셋은 **밖에서 잰 성적**(가려 놓고 맞히기)이고, AIC 는 **안에서 잰 성적**이다.
변수를 늘리면 안에서의 적합도는 거의 항상 올라가므로, **늘린 만큼 벌점(2k)** 을
뺀다. 그래서 "이 변수가 자기 몸값을 하는가" 를 묻는 지표다.

> ⚠ **AIC 값 자체는 아무 뜻이 없다.** 단위가 없고 데이터 건수에 따라 통째로
> 움직인다. **행 사이의 차이(ΔAIC)만** 본다. 155.4 라는 숫자를 외울 필요 없다.

| ΔAIC (1위 대비) | 통상 해석 |
|---|---|
| 0 ~ 2 | 구분되지 않는다 |
| 4 ~ 7 | 열세 |
| 10 이상 | 확실히 열세 |

우리 표의 ΔAIC 는 **+5.6 / +7.1 / +9.8 / +17.6** 이다 — 추가 변수 중 어느 것도
1위와 "구분되지 않는" 구간(0~2)에 들지 못했다.

## 5. 표를 행별로 읽기

| 모델 | RMSE | MAE | R² | AIC | ΔAIC |
|---|---|---|---|---|---|
| **외기 온도** | **1.678** | 1.301 | **0.854** | **155.4** | — |
| 외기 온도 + 상대습도 | 1.706 | **1.293** | 0.849 | 165.2 | +9.8 |
| 외기 온도 + 대기압 | 1.721 | 1.330 | 0.846 | 161.0 | +5.6 |
| 외기 온도 + 복수기 진공도 | 1.787 | 1.404 | 0.834 | 162.5 | +7.1 |
| 전체 변수 | 1.867 | 1.440 | 0.819 | 173.0 | +17.6 |

### ① 외기 온도 — 네 지표 중 셋에서 1위

평균 **1.30 MW** 틀리고, 큰 오차까지 감안한 값이 **1.68 MW**, 회차별 갈림의
**85.4%** 를 설명한다. AIC 도 가장 낮다. **종전 3.90 MW 대비 67% 줄었다.**

### ② + 상대습도 — MAE 만 이기는데, 그 차이가 잡음이다

**MAE 1.293 으로 온도 단독 1.301 보다 0.008 MW 낮다.** 이 한 칸이 표에서 유일한
역전이라 반드시 짚힌다. 답은 이렇다.

- 39회를 **회차별로 짝지어** 재면 차이가 **−0.008 ± 0.078 MW (t = −0.10)** 이다.
  0.078 은 우연히 생기는 흔들림의 크기다. 차이가 그 **1/10** 밖에 안 된다.
- 같은 오차 39개를 다르게 요약한 **RMSE 는 오히려 나빠졌다**(1.678 → 1.706).
  MAE 만 이겼다는 것은 **큰 오차를 더 많이 냈다**는 뜻이다.
- **AIC 는 +9.8** — 파라미터 하나를 더 쓴 값어치를 전혀 못 했다.

> 말할 때: "MAE 하나는 낮지만 **이 데이터로는 구분되지 않는다**." 
> "차이가 0 이다" 라고 말하면 안 된다 — 실제로 확인한 것은 '구분 불가' 다.

### ③ + 대기압 — 전 지표 열세

네 지표가 모두 나빠졌다. 대기압은 **이론식에서 이미 반영**하고 있고(7장),
매일 재산정하는 성분이라 곡선이 더 배울 것이 남아 있지 않다.

### ④ + 복수기 진공도 — 가장 뚜렷하게 나빠졌다

MAE 가 **1.301 → 1.404 로 0.10 MW 나빠졌다.** 짝지어 재면
**+0.103 ± 0.054 (t = +1.92)** 로, 다섯 행 중 **유의 판정선(2.02)에 가장 가깝다.**
다만 방향이 **나쁜 쪽**이다 — "진공도를 넣으면 오히려 예측이 나빠질 소지가 있다".

> 진공도 질문이 나오면: 진공도는 이론식에서 이미 반영한다. 6장이 확인한 것은
> "그러고도 남는 차이를 진공도로 **더** 설명할 수 있느냐" 이고, 세 번 다르게
> 확인해 세 번 다 아니었다. 온도를 걷어내고 재면 관련성이 **−0.14**,
> 임계 **0.312** 아래다(`VACUUM_EFFECT.md`).

### ⑤ 전체 변수 — 네 지표 전부 최하위

RMSE 1.867 · MAE 1.440 · R² 0.819 · **ΔAIC +17.6**. 변수를 다 넣은 쪽이 가장
나쁘다는 것이 이 표의 결론을 가장 크게 뒷받침한다.

## 6. "변수를 더 넣었는데 왜 나빠지나" — 가장 많이 나올 질문

데이터가 **40건**이다. 변수를 늘리면 모델이 *진짜 관계* 말고 **그 40건에서
우연히 같이 움직인 것**까지 배운다. 그렇게 배운 것은 **다음 회차에서 안 맞는다.**

- 그래서 **가려 놓고 맞히는 성적(RMSE·MAE·R²)이 나빠진다.**
- 그래서 **AIC 가 파라미터 수만큼 벌점을 준다.**
- 두 관점이 서로 독립인데 **같은 방향을 가리켰다** — 결론이 단단한 이유다.

> **"억지로 섞어서 나빠진 것 아니냐"** 는 반론에는: 변수마다 길이척도를 따로
> 줘서(ARD) **필요 없으면 모델이 스스로 버릴 수 있는 구조**로 두었다. 실제로
> 추가 변수의 길이척도는 **모두 격자 상한(14.0)** 에 붙었다 — 모델이 무시하는
> 쪽을 골랐다. 즉 **나빠진 게 아니라 쓸 정보가 없었다.**

## 7. 한 줄 요약

| 지표 | 한 마디 | 방향 |
|---|---|---|
| **MAE** | 평균 몇 MW 틀리나 | 작을수록 |
| **RMSE** | 크게 틀린 회차에 벌점을 더 준 오차 | 작을수록 |
| **R²** | 회차마다 갈리는 폭의 몇 % 를 설명했나 | 1 에 가까울수록 |
| **AIC** | 변수를 늘린 값어치를 했나 (차이만 본다) | 작을수록 |

**MAE·RMSE·R² 는 한 뿌리**(같은 오차 39개)이고, **AIC 만 다른 뿌리**다.
그래서 근거를 셀 때는 "**밖에서 잰 성적과 안에서 잰 성적이 같은 결론**" 이라고
말하는 것이 정확하다. "네 개 중 셋" 은 표를 읽는 말이고, 독립된 근거는 둘이다.
