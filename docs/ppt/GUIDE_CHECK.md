# 발표자료 작성 가이드 대조 (2026-09-16)

담당 부서에서 받은 가이드와 배점표를 지금 만든 12장에 대어 봤다.
**방향은 대체로 맞다. 그런데 배점표와 대면 구멍이 네 개 보이고, 하나는 심각하다.**

세 장을 쓰고 있고, 상대적으로 원인·방안에 네 장을 쓰고 있다. 뒤집혀 있다.

## 2. 심각한 것 — AI 를 한 마디도 안 했다 (20점)

가이드의 평가내용은 **"AI·데이터·자동화 도구 활용의 적절성 · 접근 논리성 ·
업무개선과의 연결성"** 이다. 이 과제 이름 자체가 `AI Frontier` 다.

그런데 지금 12장에는 **AI 라는 말도, 무슨 방법을 썼다는 말도 없다.**
"전문용어를 빼라" 는 지시를 따라 가우시안 프로세스·커널·LOOCV 를 전부 걷어냈고,
그 결과 **20점 항목의 근거가 장표에서 사라졌다.**

> **쉽게 쓰는 것과 근거를 없애는 것은 다르다.** 내가 이 둘을 섞었다.

가이드가 답도 같이 주고 있다 — **"전문용어 최소화, 필요시 각주로 설명"**.
본문은 쉬운 말로 두고, **쓴 방법의 이름은 대고 각주로 푼다.**

| 지금 | 고칠 방향 |
|---|---|
| "후보 일곱 가지를 늘어놓고 겨루게 했습니다" | 같은 문장 + 각주 `* 가우시안 프로세스(GP) 등 7가지. 한 회를 가리고 맞혀 보는 교차검증(LOOCV)으로 채점` |
| "도구가 스스로 다시 배웁니다" | 같은 문장 + 각주 `* 회차가 쌓이면 교차검증을 다시 돌려 최적 모델을 재선정` |
| (없음) | **7장에 「쓴 도구」 한 줄** — 어떤 데이터를 어떤 방법으로 다뤘는지 |

## 3. 나머지 구멍 셋

### ① 해결 목표가 없다 (문제정의 20점 중)
평가내용에 **"해결 목표의 타당성"** 이 있다. 지금 장표에는 "무엇을 어디까지
하겠다" 는 선언이 없다. 문제 → 바로 방안으로 넘어간다.
→ **5장(문제점) 끝에 목표 한 줄.** "엑셀 4개를 하나로 합친다. 온도마다 다른
값을 쓴다." 이미 우리가 쓰는 두 기둥이 곧 목표다.

### ② '실제 적용' 증거가 빠졌다 (현업 적용성 25점 중)
평가내용 첫 줄이 **"실제 적용"** 이다. 우리는 2026-04-15 ~ 08-26 에
**시운전 9회를 병행운전**했다. 예측을 먼저 적고 실측과 대조한 기록이 있다
(편차 −0.04 MW · 9회). **이게 '실제로 쓰고 있다' 의 가장 센 증거인데 v3 에서
빠졌다.** v2 에는 있었다.
→ **10장(유지 관리)에 병행운전 실적을 되살린다.**

### ③ 협업·역할분담이 통째로 없다 (가점 +3)
평가내용 **"협업 체계 · 역할 명확성 · 공동 수행 과정"**. 작성자가 두 명인데
누가 무엇을 했는지 장표에 한 줄도 없다. **3점을 그냥 버리는 셈이다.**
→ 9장(넘어온 과정)에 **역할 구획 하나**를 더한다. 이건 내가 만들 수 없다 —
   두 분이 실제로 나눈 역할을 알려주셔야 한다.

## 4. 가이드와 어긋난 내 결정 하나 — 되돌리기를 권한다

가이드 6번이 **7단계 구성을 그대로 제시**한다.

```
개요 → 현황·문제정의 → 원인규명 → 해결방안 → 모니터링 → 개선효과 → 수평전개
```

나는 **⑤ 모니터링과 ⑥ 개선효과의 순서를 바꿨다.** "좋아졌다 → 그게 유지되나"
가 사람 머릿속 순서라는 이유였다. 그 판단 자체는 지금도 맞다고 본다.

**그런데 가이드가 순서를 명시했고, 심사표 항목도 그 순서다.** 흐름에서 얻는
것보다 "기준을 안 지켰다" 로 읽힐 위험이 크다.
→ **원래 순서로 되돌린다.**
