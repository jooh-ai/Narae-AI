 위례 공급가능용량 — 외부 회귀모델 코드 vs 현행 툴 비교 검토
================================================================================
 작성일 : 2026-08-04
 대상    : 외부 제공 회귀분석 코드(regression_analysis.py / LOOCV 모델비교 코드)
 비교기준: 위례 실측 32건, LOOCV(31건 학습 → 1건 예측) 동일 조건 실측 검증
================================================================================


[요약 결론]

 1. 외부 코드의 모델은 현행 툴보다 부정확하다.
    - 외부 최고 모델 MAE 1.59 MW  vs  현행 툴 1.34 MW
 2. 외부 코드에는 실무 적용을 막는 결함이 있다.
    - 입찰 시점에 알 수 없는 변수(복수기압 실측)를 입력으로 사용
    - 학습범위 밖(40도) 예측이 67 MW 과대 → 입찰 사용 시 페널티 위험
    - 열 인덱스 하드코딩 불일치 → 정답(CC실측)이 입력에 섞일 수 있음
    - Extended 특성의 역수항 수치 폭주(1e8) 재현됨
 3. 다만 검증 방법론은 배울 점이 있다.
    - LOOCV, out-of-fold 예측을 모아 R2 일괄계산, 결과 리포트화
    - Lasso 변수선택을 "진단 도구"로 쓰는 아이디어


================================================================================
1. 가장 근본적인 차이 — 예측 대상이 다르다
================================================================================

 항목            | 외부 코드                   | 현행 툴
 ----------------+-----------------------------+--------------------------------
 예측 대상       | CC실측(MW) 직접             | 잔차(보정값)만
                 |                             | = 실측 - 이론 - W
 설명 주체       | 회귀식이 92 MW 변동을       | 물리 성능곡선이 담당,
                 | 전부 담당                   | 회귀는 오차만 담당
 입력 변수       | 5개 (온도, 대기압, RH,      | 온도 1개
                 | 복수기압 실측/설계)         | (대기압/RH/열화는 물리식)
 -20~40도 전구간 | 학습 범위 밖은 외삽         | 물리곡선이 담당 -> 안전

 현행 방식은 통계학의 "잔차 보정(residual/bias correction)"이며,
 발전 성능시험(ASME PTC-22)에서 쓰는 표준 접근이다.
 물리모델을 먼저 세우고 그 편차만 실측으로 학습하는 구조.

2. 동일 조건(LOOCV 31->1) 실측 비교 결과
================================================================================

 방식                                  |   MAE |  RMSE |     R2 | 최대오차
 --------------------------------------+-------+-------+--------+---------
 [현행] 이론값 + 커널회귀               |  1.34 |  1.70 | 0.9970 |    4.16
 [현행] 이론값 + 구간평균 (기본값)      |  1.42 |  1.79 | 0.9967 |    4.16
 [외부] Poly2 + Ridge (외부 최고)       |  1.59 |  1.90 | 0.9963 |    3.95
 [외부] Extended + Lasso                |  1.99 |  2.59 | 0.9931 |    8.21
 [외부] Ridge (5변수)                   |  2.49 |  2.90 | 0.9913 |    6.08
 [외부] Linear (5변수)                  |  2.70 |  3.14 | 0.9899 |    6.58
 [외부] Poly2 + Linear                  |  3.22 |  4.54 | 0.9788 |   14.44
 [외부] Extended + Ridge                | 1353만| 붕괴  |  붕괴  |  1.6억
                                        (단위 MW)

 현행 방식이 모든 후보보다 정확하다. 이유:
  - 이론값(물리)이 이미 대부분을 설명 (보정 없이도 MAE 4.51 MW)
  - 회귀(보정)는 남은 4.51 MW를 1.34 MW로 줄이는 역할만 수행
  - CC실측 범위 376.4 ~ 468.8 MW (변동폭 92.4 MW)

 [주의] R2에 속으면 안 된다
  - CC 변동폭이 92 MW라서 온도 하나만 넣어도 R2 = 0.95가 나온다.
  - 목표 정확도는 +-0.5 MW인데, R2 0.99는 RMSE 2.9 MW에 해당한다.
  - 외부 코드가 BEST_BY="R-square"로 모델을 고르는 것은 이 문제에 부적합.
    => MAE / RMSE (MW 단위)로 골라야 한다.


================================================================================
3. 외부 코드에서 발견한 실제 결함
================================================================================

(1) 열 인덱스 불일치 — 가장 위험 ★

 앞부분 명세는 X 5개(온도, 대기압, RH, 복수기압실측, 복수기압설계)인데
 코드는 다음과 같다.

     X = df.iloc[:, 1:8]      # B~H 7개
     y = df.iloc[:, 8]        # I열
     ...
     X = data.iloc[:, 0:6]    # -> B~G 6개
     y = data.iloc[:, 6]      # -> H열

 우리 엑셀4 열 구성
   (날짜|온도|대기압|RH|복수기압실측|설계|CC실측|W값|이론값|보정값)
 에 그대로 돌리면:
   - X에 CC실측(정답)이 포함되고, Y는 W값(IGV)이 된다
     -> 데이터 누출 + 엉뚱한 타깃. R2가 1.0에 가깝게 나오지만 무의미하다.
   - dropna에 I열이 포함되어, I열이 비면 전체 행이 삭제된다
     ("사용 데이터 수: 0")

 => iloc 숫자 대신 반드시 컬럼명으로 지정해야 한다.


(2) Extended 특성의 역수항 수치 폭주 (재현 확인)

     test 온도 -1.9도, train 최저 1.9도
       -> shift = -2.8 -> eps(1e-8) clip -> 역수항 1e+08

 shifted = X - train_min + 1 이 음수가 되면 1e-8로 clip되어 역수가 1억이 된다.
 LOOCV에서 최저/최고 온도 점이 test가 될 때마다 폭주한다.
 (2장 표의 1353만 MW가 그 결과)
 또한 32건에 특성 35개(p > n)이므로 애초에 불안정하다.


(3) 모델 선택 편향 (winner's curse)

     25개 후보 중 LOOCV 최고 = 1.902 MW   (보고되는 값)
     같은 선택 절차를 nested LOOCV로 평가 = 2.163 MW  (실제, +0.26 낙관)

 외부 코드는 50개 모델을 비교하므로 편향이 더 크다.
 => 선택에 사용한 점수를 성능으로 보고하면 안 된다.


(4) 실무 치명타 — 예측 시점에 알 수 없는 변수

 "복수기압 실측"은 입찰 시점에 알 수 없는 값이다
 (운전 결과이자 출력의 결과). 내일 온도는 예보로 알 수 있으나
 내일 복수기압 실측은 알 수 없다.
 => 이 변수를 사용한 회귀식은 입찰에 사용할 수 없다.


(5) 외삽 붕괴

 입찰 Profile은 -20 ~ 40도 전 구간이 필요하나 실측은 -1.9 ~ 36.1도뿐이다.

   온도   | 외부 회귀   | 현행(이론+보정) |   차이
   -------+-------------+-----------------+---------
   -20도  |   467.3 MW  |     444.6 MW    |  +22.8
   -10도  |   460.5 MW  |     461.9 MW    |   -1.4
    40도  |   426.2 MW  |     359.1 MW    |  +67.1

 36도 실측이 376 MW인데 40도를 426 MW로 예측한다
 (온도가 오르는데 출력이 급증). 입찰에 그대로 쓰면 페널티에 직결된다.

5. 반영할 만한 것 — 검증 결과 기준
================================================================================

[검증] 정규화(Ridge/Lasso) 다변량을 현행 구조(잔차 보정)에 접목한 결과
       => 전부 나빠졌다.

 보정값 예측 방법                  |   MAE
 ----------------------------------+--------
 현행) 커널회귀 (온도)             |  1.341   <= 최적
 현행) 구간평균                    |  1.419
 접목) Poly2 + Ridge 5변수         |  2.040
 접목) Ridge 5변수                 |  2.059
 접목) Lasso 5변수                 |  2.160
                                     (단위 MW)

 => 모델 자체는 반영할 것이 없다. 다만 아래 3개는 가치가 있다.


(A) Lasso 변수선택을 "진단 도구"로 활용  [권장]

 보정값 ~ 5변수, 표준화 계수 (전체 32건 학습)

   a=0.01 -> 온도 -3.22, 복수기압실측 +0.86, RH -0.82,
             대기압 +0.30, 복수기압설계 -0.26
   a=0.1  -> 온도 -2.87, RH -0.64, 대기압 +0.04
   a=0.5  -> 온도 -2.65, RH -0.38     (복수기압/대기압 탈락)
   a=1.0  -> 온도 -2.32                (온도만 생존)

 온도가 압도적이며 마지막까지 생존한다.
 => "보정값은 온도로만 모델링" 이라는 현행 설계가 데이터로 정당화된다.
    향후 변수 추가를 검토할 때 이 진단을 활용하면 좋다.


(B) 커널 폭(bandwidth) 자동 선택  [권장]

 현행은 3.5 고정이나, 데이터로 고르면 약간 개선된다.

   폭 1.5 : MAE 1.412
   폭 2.0 : MAE 1.347
   폭 2.5 : MAE 1.326    <= 최적
   폭 3.0 : MAE 1.328
   폭 3.5 : MAE 1.341    <= 현행
   폭 4.0 : MAE 1.395
   폭 5.0 : MAE 1.542
   폭 6.0 : MAE 1.685
   폭 8.0 : MAE 1.908

 차이는 작으나(0.015 MW), 데이터가 쌓이면 최적 폭이 계속 변한다.
 LOOCV로 자동 선택하게 만들 가치가 있다
 (nested CV로 정직하게 평가하는 것까지 포함).


(C) 검증 리포트 명령  [권장]

 외부 코드의 "결과를 엑셀 여러 시트로 저장" 아이디어는 사내 공유에 유용하다.
 validate 명령으로 LOOCV 지표, 구간별 편향, 목표건수,
 실측 vs 예측 표를 엑셀로 내보내면 근거자료가 된다.


================================================================================
6. 현행 툴은 어떤 모델이며, 어떻게 검증해야 하는가
================================================================================

[정체] 2단 구조 (물리 + 통계)

 1단 (물리, 결정론)
     base_table(온도) x (1.028 / Deg) / P_corr(대기압) / K_rh(습도)
     -> 이론기준값
     엑셀2의 5중보정 곡선엔진(온도/대기압/습도/복수기/열화)의 ISO 산출물을
     동결(freeze)한 것

 2단 (통계, 데이터)
     보정값 = 실측 - 이론기준값 - W(IGV)
     -> 온도구간별 평균 (계단함수 회귀 / binned mean estimator)
     -> 또는 커널회귀 (비모수 회귀, --curve)

 최종
     현실화 = 이론(IGV 반영) + 보정값
     Net = min(Gross - Aux, 462)

 즉 "회귀 모델"이 아니라 "물리모델 + 비모수 잔차보정"이다.
 1단이 92 MW 변동의 대부분을, 2단이 남은 4.5 MW를 담당한다.


[검증해야 할 7가지]

 #  검증 항목        | 방법                             | 현재 상태
 ---+-----------------+----------------------------------+-------------------
 1  예측 정확도      | LOOCV MAE/RMSE/최대오차          | 완료
                     |                                  | 1.34 / 1.70 / 4.16 MW
 2  이론값 정합성    | 시드 32건 수기 계산과 대조        | 완료 최대오차 0.18 MW
 3  표본 충분성      | 구간별 평균의 표준오차            | 완료 목표건수 근거
 4  구간별 편향      | 각 온도구간 잔차 평균이 0인지     | 미완 리포트에 추가
 5  물리 타당성      | Profile -20~40도 단조감소 유지,   | 미완 자동검사 필요
                     | 이웃 온도 급변 없음               |
 6  시간순 검증      | 과거 N건 -> 미래 예측            | 미완 날짜 백필 후 가능
                     | (walk-forward), 실제 운영 조건    |
 7  사후 검증        | 실제 입찰 후 실측과 비교 누적     | 미완 운영 단계

 6번은 외부 코드 첫 요구사항의 "날짜순 상위 20 학습 / 나머지 테스트"와
 같은 아이디어이며 타당하다. 날짜 백필이 끝나면 바로 수행 가능하다.
 LOOCV는 미래 정보를 일부 보고 학습하는 낙관적 평가이므로,
 시간순 검증이 실제 운영 성능에 더 가깝다.


================================================================================
7. 검증 재현 방법
================================================================================

 본 문서의 모든 수치는 위례 실측 32건(measurements_seed.json)으로
 LOOCV를 직접 실행하여 산출하였다.
 외부 라이브러리(sklearn/numpy)가 없는 환경이므로
 StandardScaler / Ridge(정규방정식) / Lasso(좌표하강법) /
 Poly2 / Extended 특성을 표준 라이브러리로 직접 구현하였으며,
 수식 정의는 sklearn과 동일하다.

   Ridge : ||y - Xw||^2 + a||w||^2        -> (X'X + aI)w = X'y
   Lasso : (1/2n)||y - Xw||^2 + a||w||_1  -> 좌표하강 + soft-threshold
