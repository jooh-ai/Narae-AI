# 자재마스터 통합 도구 (MasterTool)

자재마스터 엑셀 작업 세 가지를 **하나의 대화형 도구**로 합친 프로그램입니다.

| # | 기능 | 하는 일 | 입력 |
|---|------|---------|------|
| 1 | **사양 분배** | M열 `[라벨:값]…` → O~AH 개별속성 칸에 **값만** 분배, 미매칭은 ETC로 | 자재마스터 1개 |
| 2 | **Working Q'ty** | 재고 **R열(max)** → 자재마스터 **N열** (자재 A열 매칭, 중복은 최대값) | 자재마스터 + 재고 |
| 3 | **마스터 병합** | 수정본(제어파트) → 원본에 A열 기준 반영 (B/H/J/K/L/N·O~AH) | 원본 + 수정본 |

**공통**: 대상 시트는 이름에 `위례`가 든 시트를 자동 선택 · 원본은 그대로 두고 **새 파일로 저장** · 셀 서식 보존 · 변경/신규 셀만 **빨강** 표시.

---

## 실행 방법

### A. exe 로 쓰기 (파이썬 설치 불필요)
1. `MasterTool.exe` 를 준비합니다. (아래 "exe 만들기" 참고)
2. 처리할 엑셀 파일들을 **exe 와 같은 폴더**에 둡니다.
3. exe 를 더블클릭 → 메뉴에서 번호(1/2/3) 선택 → 안내에 따라 파일 선택.
   - 파일은 목록 번호로 고르거나, 창에 **끌어다 놓거나**, 경로를 직접 입력할 수 있습니다.

### B. 파이썬으로 쓰기
```
pip install openpyxl
python master_tool.py
```
(VSCode 에서 `master_tool.py` 를 열고 F5 로 실행해도 됩니다.)

## exe 만들기

### 방법 1 — GitHub Actions 자동 빌드 (권장)
`master_tool.py` 가 푸시되면 **Build Windows EXE** 워크플로가 자동으로 exe 를 빌드합니다.
GitHub 저장소 → **Actions** 탭 → 최신 실행 → **Artifacts** 의 `MasterTool-windows` 를 내려받으세요.
(수동 실행: Actions 탭에서 워크플로를 열고 **Run workflow**.)

### 방법 2 — 내 윈도우 PC 에서 빌드
파이썬이 설치된 윈도우에서 `build.bat` 을 더블클릭하면 `dist\MasterTool.exe` 가 생성됩니다.

---

## 열 위치 설정
표준 마스터 기준으로 열이 고정되어 있습니다. 다르면 `master_tool.py` 상단
**"기본 열 설정"** 상수(예: `SPEC_COL`, `WQ_INV_VAL`, `MG_VALUE_COLS` 등)를 수정하세요.
